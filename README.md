# IcoCraft

Generador de iconos `.ico` a partir de una imagen (PNG, JPG o WebP).

## Desarrollo

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: servidor de desarrollo
- `npm run build`: type-check + build de producción
- `npm run lint`: ESLint
- `npm run format`: Prettier
- `npm run test`: pruebas unitarias (Vitest)
